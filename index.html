    Survivatorium Player's Guide¶

    Welcome to the official player guide for Survivatorium, a DayZ server running on the DeerIsle map with extensive modding for an enhanced survival experience.

    Essential Information¶

    Server Rules (Summary)¶

    • KOS allowed
    • No combat logging
    • Maximum 2 bases per group
    • No grief raiding
    • 500m build restriction from military areas

    Currency¶

    The server uses Hryvnia as the primary currency. Earn money through: - Completing quests - Selling items at traders - Player-to-player trading

    Getting Help¶

    • Check individual guides for detailed information
    • Review server rules at spawn
    • Contact admins for rule clarification
