    Survivatorium Player's Guide - Implementation Plan¶

    Overview¶

    This document outlines the implementation plan for comprehensive wiki-style player guides for the Survivatorium DayZ server running on the DeerIsle map.

    Folder Structure¶

    PlayersGuide/
├── README.md                      # Index & navigation
├── GUIDE_PLAN.md                  # This file
├── images/                        # Screenshots folder (to be populated)
├── 01-Getting-Started.md          # Server rules, mod list, first steps
├── 02-Base-Building.md            # BBP, territories, raiding, code locks
├── 03-Quests-Traders.md           # Quest NPCs, questlines, market, currency
├── 04-Combat-Weapons.md           # TF/FOG weapons, Real-World Ammo, skills
├── 05-Survival-Systems.md         # Inedia stamina, Terje medicine/radiation
├── 06-Vehicles.md                 # Keys, lockpicking, towing, helis, boats
├── 07-KeyRooms-Airdrops.md        # BS KeyRoom keys, loot pools, airdrops
└── 08-Advanced-Topics.md          # Reputation, P2P market, personal storage

    Server Configuration Summary¶

    Core Settings¶

    • Map: DeerIsle
    • Currency: Hryvnia (ExpansionBanknoteHryvnia)
    • Raiding: 24/7 enabled

    Territory System¶

    • Radius: 60m
    • Max Members: 5
    • Max Territories Per Player: 1
    • Build Restriction: 500m from military areas

    Raiding Configuration¶

    • Raid Time: 24/7 (all hours)
    • Propane Torch: 600 seconds (10 minutes)
    • Explosives: Enabled

    Vehicle System¶

    • Key Required: Yes
    • Lockpick Chance: 40%
    • Lockpick Time: 120 seconds
    • Towing: Enabled

    Stamina (Inedia)¶

    • Overload Threshold: 105kg
    • Surface/Slope Modifiers: Enabled

    Reputation System¶

    • Maximum Reputation: 16,000
    • Death Penalty: -250 reputation

    Rarity Tiers¶

    1. Poor
    2. Common
    3. Uncommon
    4. Rare
    5. Epic
    6. Legendary
    7. Mythic
    8. Exotic

    Server Rules Summary¶

    From TerjeSettings/StartScreen/ServerRules.md: - KOS Server - Kill on Sight allowed - No combat logging - Maximum 2 bases per group - No grief raiding (raid only if you need access) - 500m build restriction from military areas

    Quest System Analysis¶

    Quest NPC IDs Identified¶

    • ID 1: Quest Board (main hub)
    • ID 2: STAG Medical Chief Officer Peters
    • ID 6: STAG Threat Intelligence Officer Harris

    Quest Categories¶

    1. First Login (900): Orientation quest - 500 Hryvnia reward
    2. Medical Support (100-112): Medical Chief Peters questline
    3. Hunting (001-018): Various animal hunting quests
    4. Supply Run (101-108): Supply retrieval quests
    5. Threat Intelligence (500-520): Combat-oriented quests
    6. Field Validation (621-628): Progression quests
    7. Mopping Up (601-610): Clear area quests
    8. AI VIP Escort (300-305): VIP protection missions
    9. Treasure Hunt (401-402): Location-based quests

    Key Quest NPCs¶

    • STAG Medical Chief Officer Peters
    • STAG Threat Intelligence Officer Harris
